# 🏦 Bank Management System

A console-based Banking Management System built with Python.

The project simulates basic banking operations and provides a simple command-line interface for managing user accounts and transactions.

## ✨ Features

* Create a new bank account
* Login using an account number and PIN
* Deposit money
* Withdraw money
* Check account balance
* View transaction history
* Manage account details
* Prevent duplicate account numbers
* Basic input validation

## 🛠️ Technologies Used

* **Python 3**
* Dictionaries
* Functions
* Loops
* Conditional statements
* Input validation

## ▶️ How to Run

1. Clone the repository:

```bash
git clone https://github.com/Git-byAbdullah/Bank-Management-System.git
```

2. Open the project folder:

```bash
cd Bank-Management-System
```

3. Run the program:

```bash
python main.py
```
